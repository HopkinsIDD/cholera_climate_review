# cholera_climate_review
Systematic review of cholera and climate
## About
This project is a systematic review about assications between cholera and climate with a focus on precipitation, temperature, floods, and droughts.
## Overview
This repository includes raw data, generated datasets, analysis scripts, and summary notebooks.
## Data Description
### Climate zone raster data (`climatic_zone_raster`)
This folder contains a high-resolution global Köppen–Geiger climate classification maps available from [Global Hydroclimate (GloH2O) dataset](https://www.gloh2o.org/koppen/). It also includes a dictionary file that maps the detailed Köppen-Geiger climate classifications to a more aggregated climate classification used in the analysis. 
### Endemicity data (`endemicity`)
This folder contains a csv file with annual cholera cases from WHO Annual Reports and a csv file with the country ISO codes and unique location identifiers. Both data are avaiable from [Cholera Taxonomy Databsae](https://cholera-taxonomy.middle-distance.com/)
### Extracted analytic datasets (`extracted_data`)
This folder contains both the raw and processed datasets extracted during the systematic reviews process. 
### Human Development Index (HDI) data (`hdi_raster`)
This folder contains shapefile data from both the [Cholera Taxonomy Databsae](https://cholera-taxonomy.middle-distance.com/) and [The Humanitarian Data Exchange website](https://data.humdata.org/) and subnational HDI raster avaiable from [UNDP GeoHub](https://geohub.data.undp.org/data/bb81caa483a0856029f980d2d7e89177)
### Inland and coastal index data (`inland_coast`)
This folder contains the raw coastlines data from [OpenStreetMap](https://osmdata.openstreetmap.de/data/coastlines.html) and processed datasets with generated inland and coastal index.
### Shapefile data (`shapefiles`)
This folder contains raw shapefile data for extracted locations and countires from both the [Cholera Taxonomy Database](https://cholera-taxonomy.middle-distance.com/) and [The Humanitarian Data Exchange website](https://data.humdata.org/), and the processed shapefiles generated by intersecting geographic locations with the climatic zone raster data for spatial analysis.
